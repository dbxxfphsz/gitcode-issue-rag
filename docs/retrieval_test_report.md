## 8. 结论与建议

### 检索效果总结

1. **阈值命中率 52.9%**：超过一半的测试 Issue 在知识库中找到了高相似度匹配（≥0.75）
2. **平均 Top-1 = 0.7549**：整体检索质量良好
3. **标签重合率 91.8%**：高相似度匹配通常伴随相同标签，说明向量语义与业务分类一致
4. **零失败率**：51 条查询全部成功返回结果，API 稳定性良好

### 未命中原因分析

- 11 条 Issue Top-1 < 0.70，主要为新 RFC/Feature 提案（首次提出，库中无历史对应）
- 这属于正常情况：新提案本身就是「前所未有」的，检索不到相似问题是预期行为

### 优化建议

1. **模板清洗后重建索引**：当前 embedding 基于未清洗文本，平均 24% 噪声会稀释有效语义
2. **阈值可微调**：当前 0.75 阈值偏保守，可考虑降至 0.70 提升召回率
3. **标签过滤**：可结合同标签条件提升精准度（当前纯向量匹配）
